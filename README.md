# Етап 3: Оптимізація та агрегація даних у MongoDB Atlas

## Технології
* Node.js
* Express.js
* MongoDB Atlas

## Нова функціональність

1. **Використання курсорів (`/stream-items`):**
   * **Логіка:** Замість завантаження всіх документів колекції в пам'ять сервера у вигляді масиву, маршрут використовує ітератор курсора (`for await (const doc of cursor)`). Це дозволяє потоково передавати великі обсяги даних.
   * **Приклад запиту:**
     ```bash
     curl http://localhost:5000/stream-items
     ```

2. **Агрегаційний запит (`/stats`):**
   * **Логіка:** Використовує конвеєр агрегації MongoDB (`aggregate`), який групує дані за категоріями (`$group`), підраховує загальну кількість елементів (`$sum`) та обчислює середню ціну (`$avg`).
   * **Приклад запиту:**
     ```bash
     curl http://localhost:5000/stats
     ```
